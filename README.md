# Obsidian Launcher

A Minecraft Java Edition launcher for Windows. Pick an installed version, sign in with a Minecraft access token or play offline, and launch your game.

**[Download for Windows](https://github.com/W00ky02/Obsidian-Launcher/releases/latest)**

## Features

- Local Vanilla, Fabric, Forge, NeoForge, and Quilt profiles
- Token sign-in and offline singleplayer
- Live logs, memory settings, and Discord Rich Presence
- Customizable themes and layout, in English or German
- Automatic update checks, with verified downloads and an install button

Requires Windows 10/11 x64, an existing Minecraft Java installation, and compatible Java. Obsidian does not download game files or mod loaders. All profiles share your `.minecraft` folder.

## Updates

Open **Updates → Check for updates**, then download and install the new version. Obsidian also checks at startup; you can turn this off. Finish your game before installing.
